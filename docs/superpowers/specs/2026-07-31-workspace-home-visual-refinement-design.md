# Leon AI V2.0 首页视觉优化设计

## 目标

仅优化 Leon AI V2.0 首页的视觉层级、卡片对齐、间距、文字对比度和响应式表现，使首页更接近成熟的企业级工作台。

本次不新增功能，不修改路由、AI 调用、Session State 业务结构、版本号、Secrets 或其他页面。

## 现状

首页已经通过 `TaskCard` 与 `render_task_card()` 统一渲染三个入口：

- 回复收到的邮件
- 催供应商
- 优化已有草稿

三个入口已有稳定且唯一的 Streamlit key，并分别连接现有回调或任务选择状态。本次保留这一组件和交互契约，只调整配置文案与首页 CSS。

当前主要问题：

- 主任务卡片中文字与蓝色背景的视觉对比不够稳定；
- 卡片左侧图标与边缘距离不足；
- 普通卡片的图标、文字和箭头缺少统一三列对齐规则；
- 区域标题和底部安全提醒的层级偏弱；
- 移动端需要更明确的间距与防溢出约束。

## 选定方案

采用原生 Streamlit 任务卡加统一 CSS 的方案。

- 保留 `st.button`、稳定 key、原有回调和路由；
- 保留 Streamlit 内置 Material 线性图标，避免 CDN、网络图片和新增依赖；
- 使用统一的三列网格形成“图标、文字、箭头”结构；
- 箭头由 CSS 伪元素绘制，不增加独立按钮或业务事件；
- 主卡片与普通卡片共享基础布局，`primary` 仅控制颜色和适度尺寸差异；
- 不引入自定义前端组件，不使用按钮覆盖层。

## 品牌区

首页顶部品牌区显示：

- 主标题：Leon AI Copilot
- 英文副标题：Business Communication Copilot
- 现有版本标识继续保留

品牌标题使用深色高对比度文字，副标题使用较浅灰蓝色。顶部与主要任务之间使用固定间距，不增加渐变、动画或新的“使用指南”功能。

## 区域标题

两个区域统一使用相同结构：

- 主要任务 · PRIMARY WORKFLOW
- 常用任务 · EVERYDAY TASKS

每个区域标题左侧设置短蓝色竖线。中文使用较高字重，英文使用较轻字重与灰蓝色；上下间距统一。

## 统一任务卡

`render_task_card()` 仍是首页唯一任务卡公开渲染函数。三张卡继续来自 `HOME_TASK_CARDS`，内部依旧使用原生 Streamlit 按钮。

统一结构：

1. 左侧线性图标容器；
2. 中间标题和一句说明；
3. 右侧圆形箭头。

共同规则：

- 图标、标题、说明和箭头垂直居中；
- 标题和说明左对齐；
- 图标列、文字列和箭头列宽度稳定；
- 箭头不参与独立点击，整张卡保持唯一点击区域；
- 键盘焦点、按下状态和非 hover 反馈继续保留；
- 不为单张卡片编写不同的手工 margin。

## 主任务卡

“回复收到的邮件”作为最明显入口：

- 品牌蓝背景；
- 标题使用纯白色；
- 说明使用高对比度浅色；
- 邮件回复图标置于半透明白色圆角容器；
- 圆形箭头使用半透明白色背景；
- 桌面端卡片内边距为 32px 40px；
- 图标和文字间距为 24px；
- 圆角为 20px；
- 高度适中，以内容自然撑开并设置统一最小高度。

说明文案调整为：

> 识别对方要求、必须回复的问题和潜在风险，生成专业回复。

## 常用任务卡

“催供应商”和“优化已有草稿”共享完全相同的布局规则：

- 桌面端内边距为 28px 32px；
- 图标容器约 64px × 64px；
- 图标容器使用浅蓝背景和 16px 圆角；
- 图标与文字间距为 24px；
- 标题与说明间距为 8px；
- 右侧箭头容器约 44px；
- 两张卡片使用相同最小高度；
- 两列中图标、标题、说明和箭头起始位置一致。

## 图标

沿用 Streamlit 内置 Material 线性图标：

- 回复收到的邮件：`reply`
- 催供应商：`local_shipping`
- 优化已有草稿：`edit_note`

这些图标不依赖外部 CDN 或网络资源。普通卡片图标使用品牌蓝，主卡片图标使用白色或与半透明容器形成清晰对比。

## 安全提醒

底部安全信息调整为完整信息栏：

- 左侧盾牌图标；
- 中间保留现有安全提醒与人工核对说明；
- 右侧显示“隐私与数据安全 →”作为现有产品说明区域的视觉提示，不新增页面或复杂交互；
- AI 服务、运行环境和访问保护状态继续显示；
- 背景使用浅蓝灰色，边框和圆角与任务卡体系一致；
- 移动端允许自然换行。

安全说明事实内容不改变。

## 视觉令牌

- 品牌蓝：`#2563EB`
- 深色文字：`#14213D`
- 说明文字：`#64748B`
- 浅蓝背景：`#EFF6FF`
- 页面浅色背景：`#F8FAFC`
- 卡片边框：`#DCE6F3`

间距仅使用 8、12、16、24、32、40、48px 等规则值。阴影保持轻柔，圆角在卡片体系内保持一致。

## 响应式

桌面端：

- 主任务占整行；
- 两张常用任务保持两列；
- 卡片采用水平三列结构；
- 页面内容居中并沿用现有最大宽度。

390px 移动端：

- 所有任务卡单列；
- 卡片左右内边距不低于 16px；
- 图标容器约 48px；
- 图标与文字间距约 16px；
- 箭头保持至少 44px 的视觉与触控空间；
- 描述自然换行；
- 页面和卡片不得产生横向滚动；
- 不依赖 hover 作为唯一反馈。
