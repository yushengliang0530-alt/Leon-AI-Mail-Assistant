# 免登录工作台实施与验收

规格：`../specs/2026-10-14-public-workspace-release-design.md`。用户已明确接受重启重置的限制并批准实施发布。

1. 从稳定 main 建立发布分支，保留账号分支及所有未跟踪交付物；只取 selected-03 人物资源。
2. 增加服务端共享配额守卫：UTC 日、会话 20 / 进程 200、单会话租约 10 分钟、原子计数；测试并发、跨日、异常与修复调用。
3. 移除测试码入口，所有 AI 入口注入同一守卫；不迁入账号和记录模块。
4. 用现有任务卡、路由和 selected-03 静态人物组成蓝白首页；保留三个业务 Workspace。
5. 更新文档及配置示例，运行导入和全量 Mock 测试；本地浏览器检查首页、所有入口、四个尺寸及跨会话隔离。
6. 检查提交范围与 Secrets；提交、重新核对远程、合并并推送 main；验证现有 Streamlit 应用，不创建新应用或新标签。

视觉约束：复用选定方案的 #1765bf 品牌蓝、#143356 深蓝文字、#e7f2fa 浅蓝画布、白色表面和 #63758b 次文字；系统中文无衬线字体配少量 Georgia 英文斜体。人物是唯一视觉主体，不增加动效或账号表单。桌面左右，手机入口在前、人物在后。

所有模型测试使用 Mock；部署成功只以真实远程提交与实际公开页面为证据。GitHub 网络不稳定时保留本地成果，不关闭 TLS 验证。
